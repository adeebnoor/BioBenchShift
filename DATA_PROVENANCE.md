# Data provenance

BioBenchShift is designed so that the scientific record does not depend on silently repackaged third-party datasets. Public source releases, endpoint identifiers, deterministic transformations, and checksums are recorded whenever possible.

## BioGRID temporal boundary

The historical graph and later release are treated asymmetrically by design:

1. model selection and the complete historical non-edge candidate universe are frozen using BioGRID 5.0.250;
2. later relations are identified only from BioGRID 5.0.261;
3. the later release is not used to tune the model, matching rule, or model-selection criterion;
4. the complete historical candidate universe contains **70,041,100** unknown human protein pairs;
5. **5,635** later-added relations have both endpoints observed in the historical graph and form the later-evidence set.

Database additions are treated as later evidence, not as unbiased ground truth about biology.

## ChEMBL external-evidence boundary

The ChEMBL rule was frozen before inspecting model-specific recovery:

- release: ChEMBL 37;
- organism: Homo sapiens;
- target assignment: direct SINGLE PROTEIN;
- assay type: binding;
- target confidence score: 9;
- primary support: pChEMBL ≥ 6;
- sensitivity support: pChEMBL ≥ 7.

ChEMBL evidence is not used for model training, model selection, or threshold optimization.

## Identifier mapping

BioSNAP drug identifiers are STITCH-style chemical identifiers with PubChem CID semantics; protein endpoints are NCBI Entrez Gene identifiers. External-evidence mapping uses public identifier services/resources and records mapping coverage in the frozen result tables. Mapping is treated as part of the evidence pipeline and is not silently imputed.

The contemporary GraphBAN challenge passed its prespecified mapping gate: 284/284 drugs and 3,607/3,648 genes had required features, retaining 18,631/18,690 positive relations (**99.7% edge coverage**).

## Redistribution policy

This repository preferentially stores:

- original analysis code;
- source-data tables generated by the study;
- frozen model/evaluation outputs;
- release identifiers and checksums;
- deterministic retrieval or transformation logic.

Third-party source datasets, model weights, and database content are not relicensed by BioBenchShift. Users must follow the original providers' terms. See `LICENSE` and `protocols/BENCHMARK_MANIFEST.md`.

## Historical provenance

`protocols/BENCHMARK_MANIFEST.md` preserves the acquisition plan as it existed before the analyses were completed. It should be read as provenance, not as the current result summary. Timestamped protocol amendments are retained to distinguish prespecified decisions from changes made for technical validity.
